# icaro-012026-backend
Proyecto de backend del modulo 4 de la diplomatura de fullstack de ICARO.

## Descargar proyecto

> git clone https://github.com/alezvi/icaro-012026-backend

## Instalar dependencias

> npm i

## Iniciar el servidor

> npm start

### Metodología de trabajo para issues asignados

- Actualizar siempre desde el remoto
    > git pull origin main
- Actualizar dependencias
    > npm i
- Crear una rama - No trabajar sobre main
    > git branch 2-crear-vista-parcial-para-hero
    > git checkout 2-crear-vista-parcial-para-hero
- Hacer los cambios
    > Crear archivo, modificar archivo, eliminar archivo, etc.
- Agregar cada cambio
    > git add routes/index.js
- Confirmar los cambios
    > git commit -m "nueva ruta para la pagina de registro"
- Pushear la rama
    > git push origin 2-crear-vista-parcial-para-hero
- Pull Request
- Code Review
- Aprobación
- Merge a main
